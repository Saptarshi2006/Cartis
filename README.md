## ✨ What it does

- **Wallet & budget intelligence** — tracks wallet, budget, spending pace and business health in one dashboard
- **Buy-or-wait verdict** — an AI Financial Advisor scores every purchase before you commit
- **Browser extension** — watches product pages as you shop and surfaces the verdict inline
- **Full portfolio view** — cashflow, goals, portfolio and taxes, all in one place

## 🏗️ Stack

```
Rust (Axum) · Next.js · React · Gleam · Python · PostgreSQL · GraphQL · Cloudflare Workers
```
